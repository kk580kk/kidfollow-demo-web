# KIDFOLLOW Demo Web

基于 kidfollow-core-lib 的智能童车网页演示程序

## 功能特性

- **实时传感器数据展示**: 激光雷达、超声波雷达、视觉系统数据可视化
- **交互式控制面板**: 跟随、避障、返航、紧急制动模式切换
- **3D场景模拟**: 童车与儿童跟随场景的实时可视化
- **状态监控**: 实时显示系统状态和决策信息

## 技术架构

- **前端**: HTML5 + CSS3 + JavaScript
- **核心计算**: 集成 kidfollow-core-lib Java库（通过WebSocket模拟）
- **数据源**: 模拟传感器数据流，展示真实系统能力

## 演示内容

1. **智能跟随**: 自动保持2米安全距离跟随
2. **障碍物检测**: 180°全方位感知环境
3. **紧急制动**: <50ms超快响应时间
4. **低电量保护**: 电量<20%自动返航
5. **电子围栏**: 越界自动告警和处理

## 使用说明

1. 打开 `index.html` 文件
2. 点击控制面板按钮体验不同模式
3. 观察传感器数据和状态变化

## 依赖关系

- **核心依赖**: [kidfollow-core-lib](https://github.com/kk580kk/kidfollow-core-lib)
- **部署环境**: 任何现代浏览器
